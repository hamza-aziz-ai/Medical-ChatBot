# ALTERNATIVES

Options we turned down, what each would have cost, and what would change our mind. Linked to [DECISIONS.md](DECISIONS.md).

| Area                                              | Rejected option                                                                                                | Why rejected                                                                                                                                           | Revisit if                                                                                     |
|---------------------------------------------------|----------------------------------------------------------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------|
| Answering (D-001)                                 | Generative model                                                                                               | Can invent medical facts; not inspectable                                                                                                              | Grounded generation with citations is evaluated and acceptable                                 |
| Fallback (D-002)                                  | Repair and retrain the Siamese-LSTM                                                                            | Not reproducible (no seeded split or test set, needs Kaggle data and multi-GB GloVe); returns other patients' answers                                  | A licensed, validated Q&A source and a real evaluation exist                                   |
| Bad data (D-003)                                  | Heuristic repair of malformed lists                                                                            | Invents terms                                                                                                                                          | Never for clinical facts                                                                       |
| Bad data (D-003)                                  | Refuse the whole import on one bad cell                                                                        | One row blocks 650+ diseases                                                                                                                           | Errors become frequent enough to signal a broken source                                        |
| Import (D-004)                                    | `MERGE` upserts                                                                                                | Stale facts survive re-imports                                                                                                                         | Incremental updates are needed                                                                 |
| Import (D-004)                                    | Wipe the whole database                                                                                        | Destroys unrelated data                                                                                                                                | The database is dedicated and disposable                                                       |
| Access (D-005)                                    | User accounts                                                                                                  | Disproportionate for a local prototype                                                                                                                 | Real users (Lane B)                                                                            |
| Access (D-013)                                    | Keep the shared token                                                                                          | Protected nothing that loopback binding, read-only queries and public data did not already; friction and one more secret                               | The API is exposed beyond this machine                                                         |
| Access (D-013)                                    | Make the token optional                                                                                        | More code and UI states for a deployment that does not exist                                                                                           | Same                                                                                           |
| Frontend (D-006)                                  | Keep a chat widget library on Vue 3                                                                            | Maintenance and accessibility unknown; extra dependency                                                                                                | The UI needs features the panel lacks                                                          |
| Frontend (D-006)                                  | Drop linting                                                                                                   | Loses an existing check                                                                                                                                | Never; lint is cheap                                                                           |
| CI (D-007)                                        | One orchestrator with custom change detection                                                                  | Starts a run for docs-only changes; custom diff code to maintain                                                                                       | Required status checks are enabled                                                             |
| Delivery (D-007)                                  | Deploy to a hosted server                                                                                      | No target, account or budget; putting a medical service online is the owner's call                                                                     | The owner picks a host                                                                         |
| Logs (D-008)                                      | `error_log ... crit`                                                                                           | Severity filtering keeps request lines                                                                                                                 | Never                                                                                          |
| Integrity (D-009)                                 | A separate integrity script                                                                                    | Duplicates the evaluator's driver, import and report                                                                                                   | The checks outgrow the evaluator                                                               |
| Integrity (D-009)                                 | Refuse lists of more than two departments                                                                      | Blocks the whole import for one cell                                                                                                                   | Same as the bad-data rule above                                                                |
| Merging (D-010)                                   | GitHub native auto-merge                                                                                       | Needs required checks, which path filters leave pending                                                                                                | Branch protection with a gate job                                                              |
| A-DATA (D-011)                                    | SNOMED CT / UMLS                                                                                               | Redistribution only conditional; needs licensing work                                                                                                  | A licence for a public snapshot                                                                |
| A-DATA (D-011)                                    | SemMedDB                                                                                                       | Needs credentials; final 2024 release; literature claims, not guidance                                                                                 | Never as a primary source                                                                      |
| A-DATA (D-011)                                    | HPO annotations as primary                                                                                     | Custom licence requiring unaltered content; negative annotations                                                                                       | Rare-disease scope with careful handling                                                       |
| A-DATA (D-011)                                    | PrimeKG, Hetionet                                                                                              | Mostly molecular and drug data; Hetionet has 137 diseases                                                                                              | Research use, not patient-style Q&A                                                            |
| A-DATA (D-011)                                    | Kaggle disease–symptom set                                                                                     | Provenance and clinical validation unknown                                                                                                             | Never without provenance                                                                       |
| A-DATA (D-011)                                    | Original Chinese QASystemOnMedicalKG                                                                           | Scraped, no open data licence; same lineage as the CSV                                                                                                 | Never                                                                                          |
| Conversation (D-015)                              | Server-side chat sessions                                                                                      | Stores user questions; breaks the stateless, unlogged API                                                                                              | Accounts with consent exist                                                                    |
| Conversation (D-015)                              | Automatic emergency detection by keywords                                                                      | Not validated triage; blocks educational questions such as "what causes chest pain?"                                                                   | A reviewed triage policy and evaluation exist                                                  |
| Conversation (D-015)                              | LLM-written answers                                                                                            | No reliable check catches reversed relationships or flipped negation                                                                                   | A verifiable grounding method exists                                                           |
| Suggestions (D-016)                               | Per-request availability lookup                                                                                | Unbounded connect, acquisition and read waits could delay an answer past the browser timeout                                                           | Never                                                                                          |
| Suggestions (D-016)                               | One availability query at API start                                                                            | Moves the unbounded waits into boot (gunicorn worker timeout); a cold start would silently disable chips                                               | The graph changes without the importer                                                         |
| Matching (D-017)                                  | Silent fuzzy matching                                                                                          | A near-miss can be a different disease; the user must confirm                                                                                          | Never                                                                                          |
| Matching (D-017)                                  | Broader or narrower terms as aliases ("heart attack" -> acute myocardial infarction)                           | Not an exact equivalent in the dataset; would be an inference                                                                                          | A source names the exact dataset term                                                          |
| Keyword matching (D-018)                          | Filter keyword matches by position against entity spans                                                        | Same result as masking, with more code                                                                                                                 | Never                                                                                          |
| Keyword matching (D-018)                          | Remove "infection" from the keywords                                                                           | Susceptibility questions using it would no longer abstain                                                                                              | Never                                                                                          |
| Keyword matching (D-018)                          | Mask every name, including "phenomenon"                                                                        | Changes today's answer for "what is the phenomenon of asthma" outside the bug                                                                          | The keyword is retired                                                                         |
| Releases (D-019)                                  | Tag on every merge, then dispatch release.yml                                                                  | A failed dispatch or failed gate leaves a tag with no release, and a duplicate run can tag twice                                                       | Never                                                                                          |
| Releases (D-020)                                  | Batch several merges into one release (D-019's first design)                                                   | The owner chose one release per merge                                                                                                                  | The owner asks for it                                                                          |
| Releases (D-019)                                  | A personal access token so tags start release.yml                                                              | A long-lived secret in the repository for something the workflow token can do                                                                          | Never                                                                                          |
| Releases (D-020)                                  | Release several merges in one run through a matrix                                                             | Matrix order is not guaranteed and the runs would share one artifact name                                                                              | Never                                                                                          |
| Local updates (D-021)                             | Self-hosted GitHub runner deploying from release.yml                                                           | On a public repository, other people's pull requests could run code on the owner's machine                                                             | A private repository                                                                           |
| Local updates (D-021)                             | Watchtower-style auto-updater on a moving tag                                                                  | Cannot back up, re-import the graph or roll back; needs a `latest` tag we do not publish                                                               | Never                                                                                          |
| Local updates (D-021)                             | Run each release's compose.yaml unattended                                                                     | A compose file can mount the host or change privileges; image digests do not limit that                                                                | The owner reviews every release                                                                |
| Readiness (D-022)                                 | A healthcheck script inside the container, no HTTP route                                                       | The owner chose a route the updater can also use                                                                                                       | Exposing the route becomes a concern                                                           |
| Readiness (D-022)                                 | Count diseases only                                                                                            | A graph from another CSV with the same count would pass                                                                                                | Never                                                                                          |
| Understanding (D-026)                             | Go straight to a model at runtime behind a switch                                                              | No evidence that it helps or is safe; the bar is set first                                                                                             | Step 3 passes the pre-registered bar                                                           |
| Understanding (D-026)                             | A small local model                                                                                            | The owner preferred a large hosted model; 6 GB of VRAM limits local models                                                                             | The owner wants questions kept on this machine                                                 |
| Understanding (D-026)                             | JSON-schema structured output                                                                                  | Ollama's cloud ignores `format` schemas                                                                                                                | The cloud supports structured outputs                                                          |
| Runtime model (D-027)                             | Wait for the step-3 bar before any runtime use                                                                 | The owner chose to integrate now and meet the bar later                                                                                                | —                                                                                              |
| Runtime model (D-027)                             | Rules-first (the model only on no_entity)                                                                      | Smaller gain (+14.7 points) and keeps every wrong-subject answer the rules give                                                                        | The full configuration fails a fresh holdout on safety                                         |
| Runtime model (D-027)                             | Four gunicorn threads with wider budgets                                                                       | More moving parts for the first integration; one worker keeps the in-memory budgets exact                                                              | Queuing behind model calls is a problem in use                                                 |
| Docker Hub mirror (D-030)                         | A mirror job inside release.yml                                                                                | Its failure fails the release and stops autorelease's chain; the token would pass through two workflow hops                                            | Never                                                                                          |
| Docker Hub mirror (D-030)                         | `docker buildx imagetools create` across registries                                                            | Documented as needing the source manifests in the destination registry                                                                                 | Docker documents cross-registry copies                                                         |
| Docker Hub mirror (D-030)                         | Build and push to both registries                                                                              | Untested tags reach Docker Hub before the smoke test, and the build job would hold the token                                                           | Never                                                                                          |
| Docker Hub mirror (D-030)                         | A moving `latest` tag                                                                                          | Overwritten on every release, against the rule that published tags never change                                                                        | The owner asks for it                                                                          |
| Docker Hub pages (D-031)                          | Paste descriptions and settings by hand                                                                        | Docker Hub would drift from the reviewed text                                                                                                          | Never                                                                                          |
| Docker Hub pages (D-031)                          | A second admin token only for metadata                                                                         | Same reach as the owner's existing admin token, and one more secret                                                                                    | The mirror moves to a narrower token                                                           |
| Docker Hub pages (D-031)                          | A third-party description action                                                                               | A new dependency for two HTTP calls                                                                                                                    | Never                                                                                          |
| Hosting (D-032)                                   | GitHub Pages with Jekyll                                                                                       | Static files only: no API or graph                                                                                                                     | Never                                                                                          |
| Hosting (D-032)                                   | Oracle's Ampere A1 VM with Neo4j on it                                                                         | The images are amd64-only, and the free allowance was reportedly cut in 2026                                                                           | The images become multi-architecture                                                           |
| Hosting (D-032)                                   | Hugging Face Spaces                                                                                            | Docker Spaces need a paid plan, according to their documentation                                                                                       | Free Docker Spaces return                                                                      |
| Hosting (D-032)                                   | Neo4j on the 1 GB VM                                                                                           | Neo4j alone used 1.04 GiB locally                                                                                                                      | A larger free VM                                                                               |
| Hosting (D-032)                                   | Caddy with ports 80 and 443 open                                                                               | The VM would be directly reachable; the tunnel needs no inbound port                                                                                   | The domain leaves Cloudflare                                                                   |
| Hosting (D-032)                                   | A login in front (Cloudflare Access)                                                                           | The owner wants a public demo                                                                                                                          | The site is abused                                                                             |
| Hosting (D-032)                                   | Trusting CF-Connecting-IP in the shipped nginx.conf                                                            | Every local install would trust a fixed address                                                                                                        | Never                                                                                          |
| Hosting (D-032)                                   | A separate updater for the VM                                                                                  | It would duplicate the release and digest trust checks                                                                                                 | The two modes diverge much further                                                             |
| Hosting (D-032)                                   | cloudflared at `--loglevel warn`                                                                               | Its error messages can still contain request URLs                                                                                                      | Never                                                                                          |
| Hosting (D-032)                                   | A per-request deadline in code                                                                                 | Gunicorn's watchdog and the API's driver limits bound requests; no worker kills measured yet                                                           | Measurements show worker kills under realistic failures                                        |
| Hosted model (D-033)                              | Ollama installed on the VM and signed in                                                                       | Another process on the 1 GB VM, and a signed-in device of the owner's account on a public machine                                                      | The direct API stops working                                                                   |
| Hosted model (D-033)                              | The local budgets (12 calls a minute in total)                                                                 | Up to about 17,000 calls a day of the owner's plan for strangers                                                                                       | The plan allows more                                                                           |
| Hosted model (D-033)                              | Ollama's cloud API with a key                                                                                  | Refused with HTTP 402: direct API calls need paid credits, and the owner wants the free plan                                                           | The owner buys credits                                                                         |
| Releases (D-034)                                  | A GitHub App with the `workflows` permission to create tags                                                    | A long-lived credential with write access to workflows, for a rare case the planner can avoid                                                          | A tag is refused despite matching workflows                                                    |
