# THREAT

Who could behave badly, what they could send, see or break, and what stops them. Known gaps are listed honestly.

| Actor and entry point                                                                | Worst realistic abuse                                                                         | Mitigation in place                                                                                                                                                                                                                                              | Known gap                                                                                                                                                                                                                                                                                               |
|--------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Anyone who can reach the API, `GET /?search=`                                        | Flood it; injection through the question; huge inputs; scrape the graph                       | Dev server binds 127.0.0.1 and Docker publishes only the web port, on 127.0.0.1; nginx rate limit of 10/s per client (429 beyond a burst of 20); parameterized Cypher only; read routing; 500-character limit; GET only; 5 s query timeout                       | No authentication by design (D-013): anyone on this machine can query it; the graph data is public anyway. Hosting it publicly would need real auth and HTTPS                                                                                                                                           |
| Anyone who can reach the API, a long question of unknown words                       | Keep the single API worker busy with spelling-suggestion work                                 | 500-character limit; nginx rate limit (10/s per client, burst 20); suggestions run only when no known name is found, within a 150 ms time budget                                                                                                                 | One address now gets about one second of suggestion work per minute (D-025), after which it gets plain replies; many addresses can still saturate the single worker (A-14). The address comes from nginx's `X-Real-IP`, trusted only in the API image; anything inside the Compose network is trusted   |
| The step-3 experiment, sending questions to Ollama's cloud (D-026)                   | Leak user questions to a third party; a crafted question steers the model                     | Offline script only; it reads only the synthetic `eval/understanding.jsonl`, never logs or user input; the model chooses from locally built candidate names and allowed intents, so its output never reaches a user as text                                      | A hosted model can change under the same name; prompt injection that picks a wrong but valid candidate is measured, not prevented                                                                                                                                                                       |
| Anyone who can reach the API, `GET /health`                                          | Learn whether the graph is loaded; load the database with probes                              | The body says only ok or unavailable; one count query with a 1 s timeout; nginx rate limit like every `/api/` request; questions run the same check and get 503 while the graph does not match                                                                   | None known                                                                                                                                                                                                                                                                                              |
| Anyone who can reach the API, `topic`, `topic_type`, `selection`                     | Steer the bot to another subject; inject text; flood with parameters                          | At most 10 selections of 200 characters; topic and selections must match dictionary names (and, for selections, entities in the question); used only as parameters; never logged                                                                                 | None known                                                                                                                                                                                                                                                                                              |
| Malicious web page in the same browser                                               | Call the API cross-site                                                                       | Exact-origin CORS; same-origin `/api` behind nginx                                                                                                                                                                                                               | A cross-site GET still reaches the API, but the page cannot read the answer                                                                                                                                                                                                                             |
| Hostile text in data or answers                                                      | Script injection in the page                                                                  | Text-only rendering (no `v-html`); CSP `default-src 'self'` behind nginx                                                                                                                                                                                         | —                                                                                                                                                                                                                                                                                                       |
| Anyone reading logs                                                                  | Learn users' questions                                                                        | Questions and entities never logged; nginx access and error logs discarded; gunicorn access log off                                                                                                                                                              | Third-party libraries log to `external.log`; reviewed at WARNING level                                                                                                                                                                                                                                  |
| Contributor or collaborator, pull requests                                           | Merge harmful code or data                                                                    | All checks must pass; automerge only for same-repository branches, never forks or drafts; `--match-head-commit`                                                                                                                                                  | No human review by design (D-010): a passing but wrong change merges                                                                                                                                                                                                                                    |
| Bad CSV contributor, `api/data/medical.csv`                                          | Plant false medical facts or break the graph                                                  | Field quarantine, conflict exclusion, refusal guards, integrity check, reviewed baseline counts                                                                                                                                                                  | Plausible but false facts pass every structural check; no clinical review (D30)                                                                                                                                                                                                                         |
| Contributor editing `api/dictionary/aliases.json`                                    | Map a common term to the wrong disease                                                        | Each entry needs a source URL and an existing target of the stated type (tests and load-time checks); reviewed commit                                                                                                                                            | A sourced but wrong mapping still passes the structural checks                                                                                                                                                                                                                                          |
| Whoever can publish a release (GitHub account or workflow)                           | Ship a release that takes over the owner's machine through the updater                        | Only digest-pinned images from this repository's packages, a manifest that must match, a passed evaluation, and a `compose.yaml` identical to the one the owner enrolled; anything else is refused before the stack is touched                                   | Malicious images with an unchanged compose file still run, inside their containers                                                                                                                                                                                                                      |
| Compromised dependency or action                                                     | Run code in CI or the images                                                                  | Exact pins, actions by SHA, base images by digest, Dependabot, `yarn audit`                                                                                                                                                                                      | A pinned package could still be malicious upstream                                                                                                                                                                                                                                                      |
| Release workflow                                                                     | Publish an untested or overwritten image                                                      | Tag must be on main and stable SemVer; all gates at that SHA; smoke test of exact digests; no overwrites, no `latest`                                                                                                                                            | —                                                                                                                                                                                                                                                                                                       |
| Someone with the repository's secrets                                                | Reach the Neo4j database                                                                      | Secrets only in git-ignored `.env`; CI uses a throwaway password; old password rotated (D11)                                                                                                                                                                     | `.env` is plain text on the developer machine                                                                                                                                                                                                                                                           |
| A tampered download in the dataset pilot                                             | Exploit the XML parser or redirect the download                                               | Allow-listed HTTPS URLs checked before each request; redirects refused; 100 MB cap; Expat 2.7.2 or newer, entity declarations rejected, no external DTD; offline tool, never at runtime                                                                          | A tampered source would only skew the pilot's counts                                                                                                                                                                                                                                                    |
