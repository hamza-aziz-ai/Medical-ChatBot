# FAILURE

How the system fails, dependency by dependency, and how we would notice.

| Dependency or limit                                                                                                    | If it is slow, down, wrong or empty                                                                                       | What the user sees                                                                                                                                                              | How we notice                                                                                                                                                                                                                                                       |
|------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Neo4j down                                                                                                             | Driver raises ServiceUnavailable or SessionExpired                                                                        | 503 "The knowledge graph is unavailable"; the page shows a fixed error and recovers on the next question                                                                        | `main.log` error with the exception type; Compose healthcheck on Neo4j                                                                                                                                                                                              |
| Neo4j slow                                                                                                             | Query exceeds `NEO4J_QUERY_TIMEOUT` (5 s)                                                                                 | 503, same message                                                                                                                                                               | `main.log` "query timed out"                                                                                                                                                                                                                                        |
| Stack updater (`scripts/update_stack.py`)                                                                              | A new release fails to pull, import, start or answer                                                                      | The previous release is restored, from the verified backup once one was taken; a pull failure changes nothing                                                                   | `logs/<year>/<Month>/update_stack.log`; `deploy/failed.json` names a release that is not retried; a failed recovery leaves the app stopped and `deploy/journal.json` marked, see ROLLBACK.md                                                                        |
| Graph empty or stale (no import yet)                                                                                   | Queries return no rows                                                                                                    | "I cannot answer..." for every question                                                                                                                                         | `GET /health` returns 503 and Docker marks the API unhealthy when the graph is empty, wrong-sized or from another CSV (D-022); the CI evaluation catches the rest                                                                                                   |
| A client's spelling-suggestion budget is used up (D-025)                                                               | Long or many questions of unknown words from one address                                                                  | That address gets plain "I couldn't find..." replies without "Did you mean...?" until its credit refills (about a minute)                                                       | One INFO line in `chatbot_graph_logic.log` when denial starts, without the address                                                                                                                                                                                  |
| Ollama or its cloud model down, slow or unusable (D-027)                                                               | Connection refused, a timeout or a reply that fails validation                                                            | That question is answered by the rules; after 3 transport failures in a row the model is skipped for 60 s, then one probe is tried                                              | `understanding.log`: the outcome and elapsed time, never the question; the breaker logs when it opens and closes                                                                                                                                                    |
| A client or the whole API is over the model's attempt budget (D-027)                                                   | More than 2 at once, 6 per minute from one address, or 12 per minute overall                                              | Those questions use the rules until the budget refills                                                                                                                          | One INFO line per skipped call in `understanding.log`, without the address                                                                                                                                                                                          |
| Import interrupted between the graph commit and the dictionary file, or its commit outcome unknown                     | Graph and dictionary come from different imports; a running API keeps the dictionary it read at start                     | Answers may use a stale dictionary; `/` keeps answering                                                                                                                         | The importer exits 1 with the recovery: fix, rerun the same import, restart the API, check `GET /health`. Any plan mismatch, including a different importer on the same CSV, makes `/health` and every question answer 503 until repaired (D-023)                   |
| A listed intent has no rows (graph changed without the importer)                                                       | A clean "nothing recorded" reply                                                                                          | No error                                                                                                                                                                        | The MLOps chip check fails in CI                                                                                                                                                                                                                                    |
| `entities.json` has no intents table, or cannot be read                                                                | Answers still work                                                                                                        | No suggestion chips                                                                                                                                                             | `chatbot_graph_logic.log` warning at start; re-run the importer                                                                                                                                                                                                     |
| API down (Docker)                                                                                                      | nginx cannot reach it                                                                                                     | 502 or 504; the page shows a fixed error                                                                                                                                        | Container status; nothing in nginx logs by design (D-008)                                                                                                                                                                                                           |
| API slow                                                                                                               | Frontend aborts after 10 s                                                                                                | Fixed error message; input re-enabled                                                                                                                                           | Browser only; no server-side metric                                                                                                                                                                                                                                 |
| gunicorn single worker                                                                                                 | Requests queue behind each other                                                                                          | Slower replies under concurrent use; with the model on, every request waits behind a model call of up to 2 s (measured: `/health` took 1.64 s during a 1.88 s call)             | First limit expected as usage grows                                                                                                                                                                                                                                 |
| Importer write fails                                                                                                   | Transaction rolls back to the previous snapshot                                                                           | Nothing changes                                                                                                                                                                 | Importer exits non-zero; `build_medicalgraph.log`                                                                                                                                                                                                                   |
| Dictionary publish fails after the graph commits (D35)                                                                 | Graph is new, `entities.json` is old                                                                                      | New diseases are not recognised                                                                                                                                                 | Importer exits non-zero with an explicit message; re-run the import                                                                                                                                                                                                 |
| Bad CSV (missing columns, unnamed rows, nothing left, department cycle)                                                | Import refused before writing                                                                                             | Nothing changes                                                                                                                                                                 | Importer error; MLOps CI fails                                                                                                                                                                                                                                      |
| Two processes logging the same module                                                                                  | Midnight rotation of shared files can fail                                                                                | Nothing                                                                                                                                                                         | A log line or a missing rotated file                                                                                                                                                                                                                                |
| GHCR or GitHub down                                                                                                    | Releases and CI pause                                                                                                     | Nothing for local users                                                                                                                                                         | Workflow failures                                                                                                                                                                                                                                                   |
| Docker Hub down or rate-limited, an expired token, or a tag conflict (D-030)                                           | The mirror run fails; the release, GHCR and the owner's stack are unaffected                                              | Nothing for local users; Docker Hub shows no new version                                                                                                                        | A failed `mirror` run in Actions; re-run `mirror.yml` with the tag                                                                                                                                                                                                  |
| Docker Hub's description route withdrawn, or a setting not taking effect (D-031)                                       | The metadata run fails and changes nothing else                                                                           | Nothing for local users; the Docker Hub page may be out of date                                                                                                                 | A failed `dockerhub-metadata` run in Actions                                                                                                                                                                                                                        |
| Aura paused (72 idle hours) or unreachable, hosted (D-032)                                                             | The API fails fast (about 11 s measured to an unreachable host) and answers 503; updates wait                             | "The knowledge graph is unavailable"                                                                                                                                            | `/api/health` 503; `update_stack.log` says it is not updating; the Aura console                                                                                                                                                                                     |
| Aura instance deleted after more than 30 paused days                                                                   | Every question gets 503                                                                                                   | Same                                                                                                                                                                            | Same; create an instance, update `.env`, import again                                                                                                                                                                                                               |
| The hosted Ollama down, signed out, or the free allowance used up (D-033)                                              | Model calls fail fast or are refused; after 3 failures the breaker skips the model for 60 s                               | Answers from the rules alone, a little slower while the model is tried                                                                                                          | `understanding.log` failure counts; sign in again with `hosted exec ollama ollama signin`                                                                                                                                                                           |
| Cloudflare or the tunnel down, or the VM reclaimed or stopped by Oracle                                                | The site is unreachable                                                                                                   | The site's maintenance page (D-035) while the edge is up; Cloudflare's error page without the Worker or when Cloudflare is down                                                 | The public checks in `hosting/oracle/README.md`; Oracle's notices                                                                                                                                                                                                   |
| A hosted update fails                                                                                                  | The previous release's graph is rebuilt and reopened; if that fails, public access stays closed                           | A short outage with the maintenance page, or Cloudflare's error page without the Worker                                                                                         | `update_stack.log`, `journalctl -u medical-chatbot-update`                                                                                                                                                                                                          |
| A page is open during a hosted update (D-037)                                                                          | It cannot send questions for about a minute, then runs the new release                                                    | A maintenance view over the page within 30 s while it is visible, then an automatic reload that keeps the conversation; a background tab notices when it is shown again         | Storage blocked or full: the page stays on the old release with its conversation until reloaded by hand                                                                                                                                                             |
| The API worker stuck (any setup)                                                                                       | Gunicorn kills it after about 30 s of silence; nginx answers 502 or 504                                                   | An error message                                                                                                                                                                | A `WORKER TIMEOUT` line in the API container's output, without the URL (BUG-003)                                                                                                                                                                                    |

Limits: 500 characters per question; 20 values per answer; 10 s browser timeout; 5 s query timeout; 120 s import transaction; one gunicorn worker. There is no alerting or dashboard: this is a local prototype.
